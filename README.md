# MockForge 🚀

MockForge is a schema-driven mock API generator that lets developers create realistic backend endpoints without building a real database or server logic. Users define models (tables, fields, types), and MockForge automatically exposes REST APIs with deterministic fake data generation.

## ✨ Features

* Create multiple projects and schemas
* Define models manually or import schema definitions
* Automatic CRUD-style mock endpoints
* Deterministic seeded data generation (same output every request)
* Optional persistent mock records support
* Modular Next.js + TypeScript + Express backend with Prisma

## 🏗️ Tech Stack

* Next.js
* Node.js + Express
* TypeScript
* Prisma ORM + PostgreSQL
* Faker.js for mock data generation
